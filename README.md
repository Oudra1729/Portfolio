# Brahim Oudra — Portfolio

Personal portfolio for Brahim Oudra, a backend-focused software developer.

## Scripts

```bash
npm install
npm run dev
npm run lint
npm run build
npm run preview
```

There is no typecheck script and no test suite. The app is React 18 with Vite and Tailwind CSS.

The Vite `base` is `/`, which matches root hosting. The GitHub repository homepage currently points to `https://portfoliooudra.vercel.app`. There is no `netlify.toml` in this repository.
